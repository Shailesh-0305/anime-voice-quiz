# 🎬 Anime Scenes Folder

Place your downloaded anime scene video clips (.mp4 or .webm) directly into this folder!

The quiz works in two phases for every question:
1. **Audio Guessing Phase**: The app plays **only the audio** of the scene while the user guesses which character is speaking.
2. **Scene Reveal Phase**: Once the user answers, the full **anime scene video + audio** plays automatically!

## 💡 Notes:
- Supported video formats: `.mp4`, `.webm`.
- You can also add your own custom scenes and characters using the **"Manage Scenes"** button in the top navigation bar of the website!
- If a video hasn't been downloaded yet, the website will show a helpful indicator without crashing.
